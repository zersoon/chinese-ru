Middle-level · 说长一点，说自然一点

适合已经会用短句沟通、想说得更长更自然的同学。这一级有三条主线：动词的体（完成体和未完成体）与过去时、将来时；运动动词（идти/ходить、ехать/ездить）和名词的格；以及租房办事和上班的场景。

B
Падежи! Их шесть.
pədʲɪˈʐɨ ix ʂɛstʲ

격이요! 여섯 개나 돼요. (gyeo-gi-yo! yeo-seot gae-na dwae-yo)

发音纠正：по-русски 与 -ться

  • по-русски 读 па-руски：по-русски pɐˈruskʲɪ，ск 后面的 и 让 к 变软。
  • -тся、-ться 读 ца：нравится ˈnravʲɪt͡sə、учиться ʊˈt͡ɕit͡sə，词尾的 тся / ться 合成一个 ц 音。
  • его 读 ево：его jɪˈvo，г 读 v。
  • 练习：Я учусь（我在学习）、Мне нравится（我喜欢），注意 ц 的音。

语法与文化

  • нравится 的主语是“被喜欢的东西”：Мне нравится литература，字面是“文学让我喜欢”，喜欢的人用与格 мне、тебе、вам。
  • “学了多久”用现在时：Я учу его два года（我学了两年，还在学），和英语现在完成进行时一样。
  • 六个格：主格、属格、与格、宾格、工具格、前置格。中级要把它们逐个用起来，先从固定搭配记。
  • 俄罗斯人听到外国人说俄语通常很高兴，会主动放慢语速，大胆开口比说得完美更重要。

课堂任务与作业

  • 两人一组：用“学了多久 / 为什么学 / 什么最难”互相访问，再向全班介绍对方。
  • 作业：录一段 30 秒的“我和俄语”，用上 нравится 和 уже。

发音纠正：重音在词尾的短尾形容词

  • занят / занята 重音移动：男性 занят ˈzanʲɪt 重音在前，女性 занята zənʲɪˈta 重音跑到最后。
  • грузинский 的 зи：грузинский ɡrʊˈzʲinskʲɪj，з 软化，-ский 读得轻。
  • ждать 的 жд：ждать ʐdatʲ 开头两个辅音紧连，不要加元音。
  • 练习：Я занят / Я занята（男女各读三遍）。

语法与文化

  • 复合将来时：буду + 未完成体不定式，Я буду ждать（我会一直等）。完成体直接变位就是将来时：напишу（我会写好）、опоздаю（我会迟到）。
  • 完成体和未完成体：俄语动词大多成对，未完成体表示过程、反复，完成体表示一次性完成。писать / написать（写），опаздывать / опоздать（迟到）。
  • Давай + 时间/动词：Давай в семь?（七点好吗？）是口语中最常用的提议。
  • 格鲁吉亚菜在俄罗斯非常受欢迎，哈恰普里（奶酪饼）和烤肉串是聚餐常点的菜。

课堂任务与作业

  • 角色扮演：一人提议，一人推辞再改约，最后定下时间地点。
  • 作业：给朋友发三条俄语消息：邀请、改时间、确认。

发音纠正：外来词的重音

  • 外来词重音常在后面：меню mʲɪˈnʲu、десерт dʲɪˈsʲert、бефстроганов bʲɪfˈstroɡənəf。
  • е 在外来词里有时读 э：кафе kɐˈfɛ、отель ɐˈtɛlʲ，е 前的辅音不软化。
  • без 在浊辅音前读 z：без лука bʲɪz ˈlukə；在清辅音前读 s：без сахара。
  • 练习：первое、второе、десерт，按上菜顺序读。

语法与文化

  • на первое / на второе：俄餐按“第一道（汤）—第二道（主菜）—第三道（甜点、饮料）”上菜，点菜时用 на + 宾格。
  • Попробуйте…：命令式“请尝尝”，推荐时最常用；对朋友说 Попробуй。
  • без + 属格：без лука（不要洋葱）、без соли（不要盐）。
  • 俄罗斯餐厅一般要主动叫服务员结账：Счёт, пожалуйста。小费通常是 10% 左右。

课堂任务与作业

  • 小组开一间“俄式餐厅”：服务员推荐，客人点三道菜并提一个特殊要求。
  • 作业：用俄语介绍一份你设计的三道菜菜单。

On the other hand, knowing two languages is better than one.

冇错！

发音纠正：лучше 与 легче

  • лучше 的 чш 读长 ш：лучше ˈlut͡ʂʂɨ，口语常读成 лутше 或 лушше。
  • легче 的 г 读 х：легче ˈlʲext͡ɕe，г 在 ч 前清化并擦化成 х。
  • по-моему 重音在 мо：по-моему pɐˈmojɪmʊ，е 和 му 读得很轻。
  • 练习：лучше, чем… / легче, чем…，比较两样东西。

语法与文化

  • 比较句：A лучше, чем B（A 比 B 好），也可以用属格：лучше одного（比一个好）。
  • нужно + 与格 + 不定式：谁需要做……，детям нужно учить（孩子们需要学）。
  • 连接词：с одной стороны… с другой стороны（一方面……另一方面）、кроме того（此外），让论证更有条理。
  • 俄罗斯人讨论问题时很直接，说“我不同意 Я не согласен”不算失礼，但加上 по-моему 会更委婉。

课堂任务与作业

  • 小组辩论：“孩子应不应该从小学外语”，正反方各说三点。
  • 作业：录一段 1 分钟的观点表达，用上 по-моему、с одной стороны、кроме того。

发音纠正：演讲的节奏与停顿

  • 意群之间停顿：Сегодня я хочу рассказать / о том, / как я учу русский。
  • 长词重音要清楚：выступление vɨstʊˈplʲenʲɪje、заключение zəklʲʊˈt͡ɕenʲɪje、благодарю bləɡədɐˈrʲu。
  • 陈述句结尾语调下降，听众就知道这句话说完了。
  • 自评：录下演讲，检查重音、元音弱化、软硬辅音和意群停顿。

语法与文化

  • 演讲结构：开头称呼 → сначала → затем → теперь → в заключение → 感谢。
  • о том, как…：讲讲……是怎样的，用来引出一件事的过程。
  • ни + 属格：一个也不……，не понимал ни слова（一个词也不懂）。
  • 俄语演讲结束的固定说法 Благодарю за внимание（感谢关注）或 Спасибо за внимание，学术报告、工作汇报都用。

课堂任务与作业

  • 期末任务：每人做一次五分钟俄语演讲，题目自选（家乡、美食、学习经历等）。
  • 作业：提交演讲录音和讲稿，讲稿标出你用到的本级语法点（体、过去时、将来时、比较级）。
